# Shell Emulator — эмулятор командной оболочки ОС

Учебный проект: эмулятор оболочки UNIX-подобной ОС. Этап 1 — REPL.

## Требования

- Python 3.10 или выше
- Запуск из корня проекта

## Быстрый старт

```bash
chmod +x run.sh
./run.sh [имя_vfs]
```

Или напрямую:

```bash
python3 -m src.emulator [имя_vfs]
```

Если имя VFS не указано, используется `vfs`.

## Команды этапа 1

| Команда | Описание | Пример |
|---------|----------|--------|
| `ls [args]` | Заглушка, печатает имя и аргументы | `ls -la /home` |
| `cd [path]` | Заглушка, печатает имя и аргументы | `cd /tmp` |
| `exit` | Выход из эмулятора | `exit` |

Приглашение содержит имя VFS: `myvfs$ `.

Парсер разделяет ввод на команду и аргументы по пробелам (`shlex.split`).

## Обработка ошибок

```
myvfs$ foobar
foobar: команда не найдена

vfs$ ls "unterminated
Ошибка: ошибка разбора команды: No closing quotation
```

- `Ctrl+D` — выход из REPL
- `Ctrl+C` — прерывание текущей строки, возврат к приглашению

Полный пример интерактивной сессии сохранён в `demo/stage1_session.txt`.
