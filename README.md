# Shell Emulator — эмулятор командной оболочки ОС

Учебный проект: эмулятор оболочки UNIX-подобной ОС (Вариант 29).
Этап 5 — дополнительные команды.

## Требования

- Python 3.10 или выше
- Запуск из корня проекта

## Быстрый старт

```bash
chmod +x run.sh
./run.sh
```

```bash
python3 -m src.emulator \
    --vfs vfs/deep \
    --log logs/extra.xml \
    --script scripts/startup_extra.txt
```

| Параметр   | Назначение                          |
|------------|-------------------------------------|
| `--vfs`    | Путь к физическому расположению VFS |
| `--log`    | Путь к XML-файлу журнала команд     |
| `--script` | Путь к стартовому скрипту           |

## Команды

| Команда | Описание |
|---------|----------|
| `ls [-la] [path...]` | Список файлов/каталогов VFS |
| `cd [path]` | Смена текущего каталога |
| `echo [args...]` | Печать аргументов |
| `cat file...` | Содержимое файлов |
| `rev file...` | Строки файлов наоборот |
| `chmod MODE path...` | Права доступа (восьмеричные) в памяти |
| `cp src dest` | Копирование файла/каталога в памяти |
| `help` | Список команд с описаниями |
| `exit` | Выход |

Изменения `chmod` и `cp` затрагивают только VFS в памяти, не диск.

## Этапы

1. REPL — CLI, парсер, заглушки/`exit`
2. Конфигурация — `--vfs`, `--log`, `--script`, XML-лог
3. VFS — дерево в памяти, рабочие `ls`/`cd`
4. Основные команды — `echo`, `cat`, `rev`
5. Доп. команды (текущий) — `chmod`, `cp`, `help`
